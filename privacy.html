Privacy policy

This application is a personal-use bridge between one Google account and one AI assistant, both owned by the same individual. It accesses Gmail, Calendar, Drive, Sheets, Docs and Contacts of that single account via Google APIs, on that person's own private infrastructure.

  • What is accessed: only the owner's own account data, within the granted scopes.
  • Who sees it: the owner, their own server, and the AI model provider used to draft responses about that data. No third-party service receives Google data beyond Google APIs and that model provider.
  • Storage: OAuth tokens are stored locally on the owner's server, file permissions 0600. No log of message or file contents is kept beyond task outputs the owner chooses to keep.
  • Sharing: none. No sale, no analytics, no ads, no tracking.
  • Deletion: the owner can revoke all access at any time via Google's security page (google.com/account/security) or by deleting the token files on their server; revocation takes effect immediately.
  • Retention: as long as the owner keeps the application; deletable instantly.

Last updated: November 2026.
